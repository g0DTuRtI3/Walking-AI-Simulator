# Walking AI Simulator
A Java-based simulator for experimenting with artificial intelligence that learns to walk using evolutionary algorithms and physics-based modeling.

![License](https://img.shields.io/github/license/g0DTuRtI3/Walking-AI-Simulator)
![Gradle](https://img.shields.io/badge/build-Gradle-green.svg)

  

##  Overview
**Walking AI Simulator** is a simulation framework where virtual agents learn to walk in a 2D physics environment. It applies principles from AI (such as neural networks and genetic algorithms) to evolve walking behaviors over generations.

This project is great for learning:
- Physics simulations in Java
- Evolutionary strategies
- Neural networks for control systems
- JavaFX for visualization

  

## Features

- Real-time 2D simulation of walking agents
- Physics-based environment using custom mechanics
- Evolution of AI over multiple generations
- Configurable neural networks
- JavaFX-based UI for visual inspection
